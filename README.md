# Ñe’ẽry — sitio de proyectos escolares

Sitio estático para GitHub Pages, con secciones de Lengua Castellana e Idioma Guaraní.

## Publicar en GitHub Pages
1. Descomprimí el archivo ZIP.
2. Entrá al repositorio `neery-proyectos`.
3. Elegí **Add file → Upload files**.
4. Subí el contenido de esta carpeta (no la carpeta contenedora): `index.html`, `styles.css`, `script.js`, `subpages.css`, páginas HTML, y la carpeta `documentos`.
5. Confirmá con **Commit changes**.
6. Abrí **Settings → Pages**.
7. En **Build and deployment**, elegí **Deploy from a branch**; branch `main`, folder `/(root)`, y guardá.
8. Esperá unos minutos y abrí `https://danielwarkentin1910.github.io/neery-proyectos/`.

## Notas
- La página usa fotos de Unsplash por URL, por lo que necesita conexión a Internet para mostrarlas.
- Los PDFs se pueden abrir en otra pestaña y descargar. El comportamiento de PDF dentro de la pestaña depende del navegador.
- La sección de vídeos está preparada; agregá enlaces de YouTube o archivos de vídeo confirmados para esta materia.
- Antes de publicar, revisá los títulos y nombres de los documentos para corregir cualquier error de origen.
